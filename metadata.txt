    Clip rasters in batches using polygon AOI features or selected boundaries.
    Name or group outputs from an AOI attribute and create a GeoTIFF master for every job.
    Export optional PNG, JPEG, JPEG2000, VRT, or MBTiles copies and load results into QGIS.
    Apply the selected Target CRS to every non-MBTiles output and create standards-compatible EPSG:3857 MBTiles.
    Add tiled GeoPackage output for a tile database that keeps the selected Target CRS.
    Retain Source CRS when transformation is disabled and verify the CRS written to each result.
    Preserve the source pixel grid and write portable raster display metadata for QGIS, ArcMap, and other GIS software.
    Show cancellable 0-100 percent progress from validation through completed output creation.
